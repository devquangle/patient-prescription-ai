# Phòng khám Mini

Dự án ứng dụng web quản lý phòng khám mini - Tiếp nhận bệnh nhân và kê đơn thuốc.

## Công nghệ sử dụng
- HTML5, CSS3, JavaScript ES Module
- Vite
- Vitest cho Unit & Business Test
- Playwright cho E2E/UI Test
- GitHub Actions cho CI/CD

## Cài đặt
```bash
npm install
```

## Khởi chạy
```bash
npm run dev
```

## Kiểm thử
- Chạy tất cả test: `npm run test:all`
- Unit Test: `npm run test:unit`
- Business Test: `npm run test:business`
- Test Coverage: `npm run test:coverage`
- E2E Test: `npm run test:e2e`
